# FocusFlow — Week 3 JavaScript Internship Task

A responsive task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add tasks with high, normal or low priority
- Complete and delete tasks
- Filter all / active / completed tasks
- Search tasks
- Live completion progress
- Form validation and duplicate-active-task prevention
- Save tasks in browser localStorage
- Responsive layout

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Files
- `index.html` — semantic page structure
- `style.css` — styles and responsive layout
- `script.js` — DOM interactions, validation and localStorage
- `DOCUMENTATION.docx` — technical documentation
- `REPORT.docx` — internship submission report

## GitHub
Create a new public repository, upload these files, and use the repository URL in your internship submission. Do not include passwords, tokens or personal credentials.
